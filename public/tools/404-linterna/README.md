# 404-linterna — stdio.mx

Aplicación independiente extraída del sitio PHP de Mauricio. No requiere PHP, Node ni compilación.

## Ejecutar
Desde esta carpeta: `python -m http.server 8080 --bind 127.0.0.1`. Abre http://127.0.0.1:8080.

## Repositorio propio
Copia **el contenido de esta carpeta** a una carpeta fuera de mao_git. Allí puedes inicializar Git y subirlo al repositorio que elijas. Publica su raíz con GitHub Pages. No se ha creado ni publicado ningún repositorio automáticamente.

Registra en el panel de stdio.mx la URL de la demo y, por separado, la URL del repositorio. Actualmente la demo se distribuye también dentro de stdio.mx en `tools/404-linterna/index.html`.

La Pokédex necesita conexión a PokéAPI y al servidor de sprites. La demo 404 funciona sin red y responde con una página normal para poder abrirla como experimento.
